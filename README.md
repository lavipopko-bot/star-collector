# Star Collector 🌟

A simple 2D browser game built for the [Stardance](https://stardance.hackclub.com/) challenge by Hack Club.

## About

Star Collector is a space-themed arcade game made with plain HTML5 Canvas and vanilla JavaScript — no build tools or frameworks required. Pilot a small ship, dodge falling asteroids, and collect stars to rack up points. The game gets progressively harder as your score increases.

## How to Play

- **Move:** Arrow keys or `A` / `D` (desktop), or tap/drag on the canvas (mobile)
- **Goal:** Collect stars (+10 points each) and avoid asteroids
- **Lives:** You start with 3 lives — lose one each time you hit an asteroid
- Game speed increases as your score climbs

## Play It

Open `index.html` in any modern browser, or play the live version here:
https://lavipopko-bot.github.io/star-collector/

## Tech

- HTML5 `<canvas>` for rendering
- Vanilla JavaScript (`requestAnimationFrame` game loop)
- No dependencies, no build step
